# Sistema de Diseño y Guía de Estilo Web

## 1. Paleta de Colores
- **Primario (Marca):** `#00BFFF` (Picton Blue)
- **Secundario / Acento:** `#32CD32` (White)
- **Fondo Principal:** `#87CEEB` (Seagull)
- **Fondo Superficies / Cards:** `#FFFFFF`
- **Texto Principal:** `#1E7B1E` (Bilbao)
- **Texto Secundario:** `#6C757D` (Gris Medio)
- **Estados (Éxito / Error):** `#2B9348` / `#D90429`





## 2. Tipografía
- **Titulares (H1, H2, H3):** 'Inter', Frutiger | Bold (700) | Line-height: 1.2
- **Cuerpo de texto:** 'Inter', Frutiger | Regular (400) | Line-height: 1.6
- **Tamaños base:** H1 (2.5rem), H2 (2rem), H3 (1.5rem), Body (1rem)

## 3. Principios de Diagramación y Layout
- **Estilo:** Toma como base la estetica Frutiger Aero, limpio, con espacio negativo amplio (padding amplio entre secciones, min 64px).
- **Esquinas / Bordes:** `border-radius: 8px` (Moderado, no completamente redondo ni totalmente recto).
- **Sombras:** Ligeras/Sutiles (`box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.05)`).
- **Grid / Responsive:** Basado en Flexbox/CSS Grid, max-width de contenedor: `1200px`.

## 4. Componentes Específicos
- **Botones Primarios:** Fondo `#2A6F97`, texto blanco, hovers con transición suave (0.2s) a `#014F86`.
- **Cards:** Fondo blanco, borde delgado `#E9ECEF`, sombra ligera al hacer hover.
